Mission control

Paste a read-only PAT and press Load. Nothing is sent anywhere except api.github.com, and this page makes no write calls — see README.md. "Remember on this device" stores the token in this browser's localStorage; left unchecked, it lives in memory only and is gone when you close the tab. Opened via file://, every local HTML file shares one storage origin in Chromium browsers, so checking "Remember" makes the token readable by any other local page you open in this profile — the token is read-only-scoped either way, but know that before opting in.
